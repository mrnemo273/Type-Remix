Grex Sans is IBM Plex Sans with grain pressed into it.

Every letter carries its own wear: edges that wobble, bites taken out of the ink, specks thrown off the edge and small knockouts inside the strokes. It reads like type that has been printed rather than rendered.

The grain is a variable axis. At 0 you have Plex Sans, untouched. At 100 the texture is fully in. In between it grows smoothly, at every weight from Thin to Bold, so you can set heavy grain on a headline and keep the text beneath it clean.

Variable axes

Grain follows size

The grain is drawn into the outlines, so it scales with the type. Tie it to font size and it stays out of the way in running text and comes forward at display sizes.

Use it on the web

@font-face {
  font-family: 'Grex Sans';
  src: url(GrexSans.woff2) format('woff2');
  font-weight: 100 700;
}
h1 { font-variation-settings: 'GRAN' 100; }
p  { font-variation-settings: 'GRAN' 15; }
